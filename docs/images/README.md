# Images

| Folder | What |
| --- | --- |
| `placeholders/` | 43 on-brand placeholder JPGs generated by `scripts/placeholders.py` — one per theme slot (hero, 6 tiles, storefront, Michele, Shop-the-Look poster, 9 collection banners, 12 sample products × 2). Uploaded to Shopify Files on `kw59hc-k1` as `beyoutiful-<slot>.jpg`; templates reference them as `shopify://shop_images/beyoutiful-<slot>.jpg`. |
| `photos-in/` | Drop zone for Michele's real photos (git-ignored). |
| `photo-map.json` | Which incoming photo fills which slot (+ vertical crop bias). |
| `final/` | Output of `scripts/swap-photos.py` — real photos cropped to slot size, same filenames (git-ignored). Re-upload to Files with `duplicateResolutionMode: REPLACE` → every page updates, zero template edits. |

Why placeholders and not stock: Facebook and Google CDNs can't be fetched from the build environment, and stock would misrepresent the shop. The placeholder set is deliberately editorial (linen ground, hairline frame, badge, Playfair label) so the preview reads finished, and every one is labeled so nobody mistakes it for a final.

Slot sizes: hero 2400×1000 · tiles 1200×1380 (theme ratio 1/1.15) · portraits 1200×1500 · collection banners 2400×800 · products 1200×1500.
