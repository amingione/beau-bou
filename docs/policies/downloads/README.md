# Downloadable policies

Corrected copies of the five Shopify store policies — address **264 W Marion Ave**, boutique phone and email (no personal contact info). Edit the text in `src/*.html`, then rebuild:

```bash
pip install python-docx htmldocx && python3 scripts/build-policies.py
```

| File | Use |
|---|---|
| `Be-YOU-tiful-Policies.zip` | Everything below in one download |
| `All-Policies.pdf` | All five, one per page — print or share |
| `<policy>.pdf` / `<policy>.docx` | Single policy — PDF to share, Word to edit |

To publish: Shopify admin → **Settings → Policies** → paste each policy's text (copy from the Word file) into the matching box → Save.
