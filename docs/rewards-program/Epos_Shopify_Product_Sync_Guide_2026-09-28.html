STEP-BY-STEP · INTERNAL

Sync products: Epos Now back-office app → Shopify

This is the native, no-code path for Step 3 — the app in Michele's Epos Now Back Office that gives a real-time, two-way sync with Shopify. Use this before ever considering a custom sync script; it already does products, stock, customers and order history.

1
Confirm Michele's Shopify account is ready

She needs an active Shopify account/store (shopbeyoutifulboutique.com, store handle v0m0hb-x3) before connecting — already true here.

2
Open the Epos Now Back Office

Log in at the Epos Now Back Office (Michele's login, or with her permission on her behalf). Go to the App Store / Apps section.

3
Find and install the Shopify app

Search "Shopify" in the Epos Now app store, or go directly to eposnow.com → Store → Apps → Shopify. Click Install.

4
Connect the Shopify account

The app prompts a Shopify sign-in / OAuth authorization — sign into shopbeyoutifulboutique.com's Shopify admin and approve the connection when prompted. This grants Epos Now read/write access to products, inventory and customers on the Shopify side.

5
Choose sync direction and scope

Confirm the app is set to two-way sync (not one-way Epos→Shopify or Shopify→Epos only). Map any category/department fields so Epos categories (clothing/shoe sizes, brands, gender, adult/kids/baby) land in the right Shopify collections and options.

6
Run the first sync as a small test

Create or edit one low-stakes product in Epos (not a live SKU) and confirm it appears correctly in Shopify — right price, size/color variants, stock count. Then edit it from the Shopify side and confirm it flows back to Epos. Do this before trusting it with real inventory.

7
Sync customers and order history

Confirm the app is also pulling customer records and past order history (it does this by default per Epos Now's own description) — this is what will let the rewards build (separate guide) match an Epos customer to their Shopify account.

8
Full inventory sync

Once the test passes, let it sync Michele's full Epos catalog. Expect this to take longer for a full catalog than a single product — Epos Now processes it in the back office and does not need to be watched live.

9
Remove the sample/TEST products from Shopify

The 18 TEST — products (55 variants) currently in the theme for testing need to be archived or deleted once real inventory is flowing, so customers never see placeholder items.

Watch for: duplicate SKUs if a product already exists on both sides before the first sync (map/merge, don't let it create a duplicate); Epos "adult/kids/baby" categories not lining up 1:1 with Shopify's collection structure (may need manual collection assignment for edge cases); and any per-transaction or per-SKU fee Epos or Faire charges for the integration — confirm before turning it on for good (flagged as still-unverified in the meeting packet).

If the native app can't do something we need

Fall back to the Epos Now REST API directly (Basic Auth with API key + secret from the Back Office, base https://api.eposnowhq.com/api/V2/Product — note V1/V2 Product endpoints are marked deprecated in favor of the V4 API) combined with the Shopify Admin API already live in the be-you-tiful app. That's a real build, not a settings toggle — see the separate Custom Rewards Build Guide for the pattern (Zapier as the connector) if a similar custom bridge is ever needed for products instead of just rewards.
