That's $180–$600/year, forever, on top of Shopify's own subscription.

Why the custom route is on the table

Because Epos Now already has a native customer/loyalty-points field, and both Epos and Shopify expose an API, the same behavior — earn points per purchase, redeem for a discount, balance visible to the customer — can be wired with Zapier as the connector instead of a monthly app. Michele pays $0/mo extra once it's built; the cost is Amber's one-time build time instead of a recurring subscription. See the separate Custom Rewards Build Guide for exactly what that takes and how long it runs.

When to recommend the app instead

  • If Michele wants tiered VIP status, gamified badges, or a public rewards-page widget out of the box — that's more polish than a from-scratch build should attempt first.
  • If she wants it live in days, not weeks — an app installs same-day; the custom build has real engineering hours behind it.
  • If the store scales fast and needs a support team behind the loyalty tool — app vendors provide that; a custom build is supported by Amber alone.
